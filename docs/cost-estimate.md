# Cost estimate

Monthly cost in CAD for production plus dev and test, Canadian regions, list prices converted at USD 1 = CAD 1.41 (Bank of Canada, November 2026). Generated by `cost-model/gen_cost_md.py`; edit assumptions in `cost_model.py`.

## Summary

| Tier | Questions/mo | Users | AWS | Google Cloud | AWS per question | GCP per question |
| --- | --: | --: | --: | --: | --: | --: |
| Pilot | 1,000 | 25 | $673 | $514 | $0.672 | $0.514 |
| Production | 20,000 | 200 | $1,299 | $2,192 | $0.065 | $0.110 |
| Scale | 200,000 | 2,000 | $3,543 | $14,731 | $0.018 | $0.074 |

Per-question figures divide by user questions only; 1,000 evaluation-set runs a month are included in every tier.

Model price explains the gap: keeping inference in Canada limits each cloud to one model family today (Claude Haiku 5.5 via Bedrock Canada inference; Gemini 3.5 Flash on Vertex AI Montréal). At pilot volume fixed infrastructure dominates and Google Cloud is cheaper; from production volume, tokens dominate and AWS is cheaper.

**Basis:** S = unit price confirmed from a November 2026 source; L = published US list price scaled by a regional factor (1.10, or 1.40 for Cloud Run Tier 2); A = planning allowance. Validate L lines in the AWS and Google Cloud pricing calculators before budgeting.
